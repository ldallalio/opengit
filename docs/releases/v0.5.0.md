# OpenGit v0.5.0

OpenGit now discovers and manages all Git worktrees registered with a repository, including checkouts created outside OpenGit. Open **Worktrees** in the repository sidebar or choose **Manage Worktrees** from the command palette.

## Worktree management

- View each checkout's branch or detached commit, location, lock state, availability, and staged, unstaged, untracked, and conflict counts.
- Create a checkout with a new branch, an available existing branch, or a detached commit. Branch and commit menus can preselect the starting point.
- Open a checkout in OpenGit, reveal its folder, or open it in the configured editor.
- Lock, unlock, move, repair moved checkouts, and preview stale registrations before pruning them.
- Preview removal before confirming it. Removal blocks dirty, locked, conflicted, or otherwise unsafe checkouts; ignored files require acknowledgement. Branches are retained.
- Keep commit drafts, amend mode, and selected views separate while switching between checkouts during the session.
- Open the existing checkout for an occupied branch and prevent branch operations that would affect another checkout unexpectedly.

This release also adds remote branch deletion to the branch menu, with confirmation and protected-branch checks.

## Downloads and updates

The release workflow builds macOS for Apple Silicon and Intel, Windows x64, and Linux x64. Official updater archives have Tauri signatures. macOS code signing and notarization depend on the configured Apple release credentials; Windows installers remain unsigned. Local source builds do not acquire those release signatures automatically.

Native Git must be installed and available on `PATH`. See the [release checklist](../release-checklist.md) and [signing and updates guide](../signing-and-updates.md) for build and verification details.
